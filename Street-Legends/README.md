# Street Legends

## Run the game

1. Extract the ZIP file.
2. Open a terminal in the extracted folder.
3. Run `npm install` once.
4. Run `npm start`.
5. Open `http://localhost:3000` in a browser.

Do not open `public/index.html` directly; the game needs to run through its local server.

The game itself runs without extra setup. Ally's AI chat needs an `XAI_API_KEY` in a local `.env` file.
